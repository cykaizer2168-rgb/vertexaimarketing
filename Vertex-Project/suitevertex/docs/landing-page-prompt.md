# SuiteVertex — Landing Page Build Prompt

> Saved spec/prompt for a future build. Not yet implemented.

Create a modern landing page for "SuiteVertex" inspired by suitecrew.net, but do NOT copy the brand, wording, layout exactly, or assets.

## Goal
Design and build a premium SaaS-style landing page for SuiteVertex, positioned as:
**"AI + ERP + Automation Team as a Service"**

## Target market
US mid-market companies, finance teams, operations teams, eCommerce teams, and businesses using NetSuite, HubSpot, Shopify, Celigo, n8n, or custom ERP tools.

## Tech stack
- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Responsive desktop/tablet/mobile
- Use clean reusable components
- Use lucide-react icons
- No backend required
- Use placeholder CTA form/modal only

## Design direction
- Premium dark SaaS theme
- Clean typography
- Rounded cards
- Subtle gradients
- Modern enterprise look
- Inspired by SuiteCrew's direct, honest, subscription-based positioning
- Add dashboard/backlog mockup section
- Avoid generic agency design

## Brand
- **Name:** SuiteVertex
- **Tagline:** ERP, AI Automation, and Integration Work — on a Monthly Plan.

## Hero section
- **Headline:** "Your ERP, AI Automation, and Integration Team — on a Monthly Plan."
- **Subheadline:** "NetSuite support, integrations, workflows, AI agents, CRM automation, and custom internal tools handled by senior consultants for one predictable monthly fee."

- **Secondary CTA:** "See plans"
- **Hero badges:**
  - Month-to-month

  - Typical response under 1 business day

## Important style requirements
- Make it look premium and enterprise-ready
- Avoid cartoon illustrations
- Use dark navy/black background with blue/violet accents
- Use white and muted gray typography
- Use cards with subtle borders
- Make the pricing section very clear
- Make the dashboard mockup realistic
- Make it mobile responsive
- Use polished spacing and section hierarchy

## Tone of copy
Direct, confident, honest, practical. Not hype-heavy. Position SuiteVertex as a senior technical operations partner, not a generic agency.
